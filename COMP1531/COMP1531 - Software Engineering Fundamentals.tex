	\section{Introduction to Software Engineering}

		What is the difference between Computer Science and Software Engineering.

		\begin{itemize}
			\item Computer science focuses on understanding how computers work and function
			\item Software engineering is about creating software for people to use, and building software that is maintainable over time
		\end{itemize}

		The Software Development Life Cycle is a structured approach to software development that includes:

			\begin{itemize}
				\item Requirements analysis
					\begin{itemize}
						\item Talk to potential clients
						\item Work out what is needed of the software
					\end{itemize}
				\item Design
					\begin{itemize}
						\item Designing an outline for the software
					\end{itemize}
				\item Development
					\begin{itemize}
						\item Writing the actual code to handle the task
					\end{itemize}
				\item Testing
					\begin{itemize}
						\item Test the program to see if it meets the initial requirements
					\end{itemize}
				\item Deployment
					\begin{itemize}
						\item Deploy the software to users
					\end{itemize}
				\item Maintenance
					\begin{itemize}
						\item Continue to develop, fixing bugs and implementing new features
					\end{itemize}
			\end{itemize}
		
		Software quality and productivity is supported by three key pillars: people, technology, and processes.

			\item Prototyping - get early feedback

	\section{JavaScript}

		\begin{itemize}
			\item Developed in 1995 so Netscape could add scripting to their browser
			\item Extensively used by large tech companies
			\item Front-end software
			\item NodeJS compiles and runs JavaScript code
			\item NodeJS is interpreted, ie. a high level language. The code gets interpreted before it gets compiled into machine language.
			\item JS type shenanigans
			\item \mintinline{js}{let} creates a variable that can be reassigned
			\item \mintinline{js}{const} creates a variable that cannot be reassigned. However, objects can still be manipulated.
			\item \mintinline{js}{${variable}} can be used to insert the value of a variable into a string
		\end{itemize}

		\begin{itemize}
			\item Strings
				\begin{itemize}
					\item String concatenation can be performed using \mintinline{js}{+}, eg. \mintinline{js}{"some text" + variable}
					\item Adding variables into strings can be done using string interpolation, eg. \mintinline{js}{`Hello, my name is ${name}`} (where \mintinline{js}{name} is a variable)
				\end{itemize}
			\item Control structures
				\begin{itemize}
					\item Very similar syntax to C, nothing important to note
				\end{itemize}
		\end{itemize}

		\subsection{Data Structures}

			\begin{itemize}
				\item Data structures are designed to scale complex tasks
				\item Two important data structures that are both collections of data are
					\begin{itemize}
						\item Sequential collections - indexed things such as arrays
						\item Associative collections - values are referenced by a string key that maps it to a value, in JS is an object
					\end{itemize}
			\end{itemize}

			\begin{minted}{js}
				let student = {};

				student.name = "Jake";			// or student["name"]
				student.age = 25;
				student.country = "Australia";

				console.log(student);

				console.log(Object.keys(student));
				// OUTPUT: [ "name", "age", "country" ]

				console.log(Object.values(student));
				// OUTPUT: [ "Jake", 25, "Australia" ]

				console.log(Object.entries(student));
				// OUTPUT: [ 
				//	["name", "Jake"], 
				//	["age", 25],
				//	["country", "Australia"]
				//]
			\end{minted}

			\begin{itemize}
				\item Arrays and objects have methods
				\item Objects are the only none primitive type
			\end{itemize}

\chapter{Git}

	To effectively work on large projects with multiple people, we need advanced methods of managing the codebase. Simple file sharing is insufficient.

	Git is a program that allows distributed version control where each user has a full backup. Work can also be stored in the cloud. GitHub, GitLab, and BitBucket are software tools that implement git via a web app (COMP1531 uses GitLab). 

	Git can be used as
	\begin{enumerate}
		\item Version control on a single machine
		\item Version control across multiple of your machines
		\item Version control across a team of engineers
	\end{enumerate}

	Files are added to a staging area with \mintinline{bash}{git add .}, where \mintinline{bash}{.} refers to all changes. The staged changes can be committed to the working tree with \mintinline{bash}{git commit -m "message"}. Finally, to export the changes into the cloud, \mintinline{bash}{git push} can be used.

	\mintinline{bash}{git diff} shows the difference between the working directory and staged directory.

\chapter{Importing Libraries}
	
	Libraries allow us to use code that other people have written in our own projects. In JavaScript, we can do so by adding the header \mintinline{js}{import fs from 'fs'}. Unlike C, the functions that are important can not be directly called. Instead, the functions exist as methods on objects, where the object name is specified when the library is imported.
	\\ \\
	We can also import our own code in other files. The functions that we want to use elsewhere can be exported by adding \mintinline{js}{export} or \mintinline{js}{export default}. The \mintinline{js}{default} keyword means that when the function is imported it will run the defaulted command. This is useful when providing an alias for the function.
	\\ \\
	Functions from other people can be downloaded into our directory using npm. Running npm init will create a package.json that has the information required modules to tell other people what to install. Installed packages are added to the node\_modules folder. This folder is gitignored to save space.
